# github-cleanhub

This repo is a reference, not an app. Its one skill is `github-bullseye`,
linked at `.agents/skills/github-bullseye`. Read it before any GitHub work.

- Changes to the skill go through the skill's own recipe: an issue, a branch,
  a pull request, a comment review, a squash merge. Practise what it says.
- Keep `references/what-counts.md` honest. Mark each rule as verified (with
  the date and how) or unverified. Never upgrade a guess to a rule.
- `scripts/bullseye.sh` must keep working with only `gh` and standard shell
  tools. Test it before merging a change to it.
